# Docs Sync Skill

Use this skill after meaningful code changes.

## When to update docs

Update documentation when changes affect:

1. App architecture
2. Setup instructions
3. Environment variables
4. Database schema
5. API behavior
6. Authentication or permissions
7. Deployment
8. Major UI flows
9. External integrations
10. Developer workflow

## Rules

1. Do not over-document trivial changes.
2. Prefer concise updates.
3. Keep CLAUDE.md useful for future AI sessions.
4. If Graphify is used, mention whether the graph may need an update.
5. Summarize changed behavior clearly.
