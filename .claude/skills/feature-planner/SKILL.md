# Feature Planner Skill

Use this skill before implementing a new feature or large change.

## Planning output

For new features, produce:

1. Goal
2. User story
3. Current system understanding
4. Relevant files/modules
5. Data model impact
6. UI impact
7. API/server impact
8. Permissions/security impact
9. Edge cases
10. Implementation steps
11. Test plan
12. Rollback/risk notes

Use Graphify first when identifying relevant parts of the existing app.

Do not start coding a large feature until the plan is clear or the user approves the approach.
